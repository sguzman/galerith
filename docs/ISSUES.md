# 📋 Tracking queue

The [machine ledger](progress.json) owns task IDs, checks, acceptance evidence and percentages. [Roadmap](ROADMAP.md) renders it; GitHub issues are execution trackers, not acceptance evidence.

A single MVP program encompasses all milestones M0–M5. Each phase P0–P11 should have a tracker linked from the MVP parent; individual tasks keep stable IDs in the ledger. Do not use a closed issue alone as proof of complete parity.
